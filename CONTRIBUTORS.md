## How to contribute

Contributions are welcome via pull requests on [GitHub](https://github.com/transientlunatic/bagpuss).
Please ensure that:

1. New code is accompanied by tests in `tests/` using the `unittest` framework.
2. All public functions and classes carry NumPy-style docstrings.
3. `ruff check .` and `ruff format .` pass before committing (pre-commit hooks enforce this).
4. Type annotations are present on all new public symbols.
